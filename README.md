# 👥 CRM System

A **full-stack Customer Relationship Management (CRM) System** built using **React.js, Python, and MySQL** to organise leads, manage customer information, track interactions, and structure follow-up activities.

The project focuses on practical customer relationship management, bringing customer records, lead information, and follow-up workflows together in one application.

## 📌 Overview

The CRM System is a web application designed to make customer information easier to organise and manage.

It provides a structured approach to handling customer-related activities, helping users maintain records, manage leads, and keep track of follow-up tasks instead of relying on scattered information.

The project explores how a web-based application can support everyday customer management workflows through an organised interface and structured data storage.

The main areas of focus include:

* Lead management
* Customer information management
* Customer interaction tracking
* Follow-up activity management
* Organised customer records
* Practical CRM workflow design

## 🚀 Core Features

### 👤 1. Customer Management

The customer management functionality focuses on maintaining customer information in an organised and accessible format.

Key activities include:

* Managing customer records
* Maintaining customer information
* Keeping related customer details organised
* Accessing customer information when required

### 🎯 2. Lead Management

The lead management functionality focuses on organising potential customers and their associated information.

Key activities include:

* Maintaining lead records
* Organising lead-related information
* Managing customer opportunities
* Keeping lead information available for follow-up activities

### 📞 3. Customer Interaction Tracking

Customer interactions are an important part of maintaining relationships and understanding previous communication.

This area of the application focuses on organising interaction-related information so that customer activities can be referred to when needed.

Potential information includes:

* Customer interaction details
* Communication history
* Related customer records
* Notes associated with customer activities

The exact information tracked depends on the implemented functionality.

### 📅 4. Follow-up Management

Follow-up management focuses on keeping customer-related activities organised and making ongoing interactions easier to manage.

A typical CRM workflow can be represented as:

```text
Lead Identification
        ↓
Customer Information
        ↓
Interaction Tracking
        ↓
Follow-up Activities
        ↓
Ongoing Relationship Management
```

This workflow illustrates the project's overall approach to organising customer-related activities. The specific steps depend on the application's implemented features.

### 📊 5. Organised Customer Workflows

The project focuses on connecting customer records, lead information, and follow-up activities into a practical workflow.

Instead of treating each record as an isolated entry, the application is designed around the relationship between customer information and the activities associated with it.

This approach helps demonstrate how software can support everyday business processes through structured information management.

### 🗄️ 6. Customer Data Management

MySQL is used to store structured application data, while Python supports application logic and data handling.

The application brings together customer-related information in a centralised system, supporting the main CRM operations.

## 🚀 Getting Started

### Prerequisites

* Python
* Node.js and npm
* MySQL Server
* A code editor such as Visual Studio Code
* Git

### 1. Clone the repository

```bash
git clone https://github.com/itsaryanpawar/CRM-System.git
cd CRM-System
```

### 2. Install dependencies

Install the frontend and Python dependencies using the configuration files provided in their respective project directories.

For a React frontend with a `package.json` file:

```bash
npm install
```

For a Python application with a `requirements.txt` file:

```bash
pip install -r requirements.txt
```

### 3. Configure the database

* Ensure MySQL is installed and running.
* Create the database required by the application.
* Configure the database connection using the project's existing settings.
* Ensure the required tables are available.

### 4. Run the application

Start the Python application and React development server using the commands appropriate to the actual project configuration.

The exact commands depend on the repository structure and the application entry points.
